# 📚 내신 기출 문제 메이커

학교 수업 학습지(사진/텍스트)로 고등학교 내신 스타일 문제를 만들고, 과목별로 관리·풀이하는 정적 웹앱입니다. 서버·API 키가 필요 없습니다.

## 폴더 구조
```
index.html            화면
config.js             ★ 학교 이름 / 비밀번호 해시 / 접속 코드 해시 설정
css/style.css         스타일
js/generator.js       키 없이 동작하는 규칙 기반 문제 생성기
js/app.js             화면·저장·관리자 기능
data/content.json     학생들에게 공개되는 문제 데이터 (관리자가 내보내서 덮어씀)
.github/workflows/    GitHub Pages 자동 배포
```

## 사용법
1. **관리자**: 우측 상단 🔒 → 처음엔 비밀번호 설정, 이후 입력.
2. **학습지 추가**: 과목 탭 선택 → 사진 업로드 → `글자 인식(OCR)` → 인식된 글자 수정 → `문제 만들기` → 미리보기 후 `문제 은행에 추가`.
3. **더 좋은 품질**: `AI 앱에서 가져오기` 탭에서 프롬프트를 복사해 ChatGPT/Gemini/Claude 앱에 사진과 함께 보내고, 받은 JSON을 붙여넣기.
4. **문제 관리**: 문제 직접 추가·수정·삭제.
5. 사진/문제는 브라우저에 저장되어 페이지를 나갔다 들어와도 유지됩니다.

### 학생에게 공개하기 (Firebase 없이)
관리자 → `설정·배포` → `content.json 내보내기` → GitHub 저장소의 `data/content.json`을 새 파일로 덮어쓰기(커밋) → 1~2분 뒤 모든 학생에게 반영.

## GitHub 배포
1. GitHub에서 새 저장소 생성 → 이 폴더의 모든 파일 업로드(`.github`, `.nojekyll` 포함).
2. 저장소 **Settings → Pages → Source: GitHub Actions** 선택.
3. `main`에 푸시되면 자동 배포되고 `https://<계정>.github.io/<저장소>/` 로 접속.

## ⚠️ "우리 학교에서만" 접근 제한 — 꼭 읽어 주세요
- **GitHub Pages 사이트는 저장소가 비공개여도 인터넷에 공개됩니다.** 접근 제한(비공개 Pages)은 GitHub Enterprise Cloud에서만 가능합니다.
- 간이 방법: `config.js`의 `accessCodeHash`에 **학교 접속 코드 해시**를 넣으면 코드 입력 화면이 뜹니다. 단, 브라우저 코드만으로 막는 방식이라 **약한 보호**입니다. 이 경우 `data/content.json`에도 접근 가능하므로 저작권 있는 학습지 사진은 포함하지 마세요(내보내기 시 사진 포함 체크 해제 기본값).
- 확실한 제한이 필요하면: 같은 저장소를 **Cloudflare Pages + Cloudflare Access**(학교 구글 계정 도메인만 허용)에 연결하세요. 코드 수정 없이 사용 가능합니다.

## OCR·문제 생성 한계
- OCR(Tesseract.js)은 CDN에서 불러오므로 인터넷이 필요하고, 손글씨·표·수식·그림은 인식이 약합니다. 인식 결과를 꼭 확인·수정하세요.
- 키 없는 생성기는 글 속 핵심어를 이용한 빈칸/참거짓/용어 문제를 만듭니다. 계산·그래프·서술형은 `AI 앱에서 가져오기` 또는 직접 입력을 이용하세요. 생성된 문제는 반드시 검수하세요.
